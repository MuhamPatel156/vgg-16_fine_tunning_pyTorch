# VGG-16 Fine-Tuning in PyTorch

This repository contains the code and configuration for fine-tuning a pre-trained VGG-16 convolutional neural network using PyTorch. 

## Dataset

The dataset used for this project is hosted on Google Drive. You can download it using the link below:

* **[Download Dataset Here](https://drive.google.com/file/d/1A1O9rVtjMVwliNc0RdcHi_mFEEbifJ4s/view?usp=sharing)**

*(Note: Extract the downloaded files into the `data/` directory before running the training script.)*

## Requirements

Ensure you have the following dependencies installed:

* Python 3.3+
* PyTorch
* Torchvision
* NumPy

You can install the required packages using:
```bash
pip install torch torchvision numpy
